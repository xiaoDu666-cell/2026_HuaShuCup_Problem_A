问题1：确定性判断（给定坐标）实现步骤
1. 输入：CSV 中若干圆柱两端坐标，盒子尺寸 L，圆柱半径 r，长度 h（或由坐标给出），阈值 thresh。
2. 构建 Cylinder 对象列表（保留 id）。
3. 对每个 Cylinder 调用 split_cylinder_by_box() 得到片段列表（片段记录原始 cylinder id）。
4. 为每个片段计算其轴线中心或包围球（center, bounding_radius = sqrt((h_seg/2)^2 + r^2)）用于粗筛。
5. 建 KD-tree（或使用 scipy.spatial.cKDTree）对片段中心建立索引；对每个片段查询半径扩展的邻近者（radius = bounding_radius_i + max_bounding_radius + thresh）。
6. 对候选对做精确最短轴线距离计算（线段到线段距离），减去两半径得到 surface-to-surface 距离 d_surf。若 d_surf <= thresh 则在并查集中 union 两片段。
7. 标记与“左面”（x <= -L/2 + r 或轴线有端点或表面与左面接触/穿越）相连的片段集合，与“右面”同理。具体判断：如果片段轴线上任一点的 x - r <= -L/2 则视为接触左电极；对于截断的端面要考虑是否端面放置在界面上。
8. 最后并查集判断：若存在同一集合同时含左标记与右标记则导通 True。

问题2：蒙特卡洛模拟的具体流程
流程概要（对每个 f）：
1. 将体积分数 f 转换为整数颗粒数 N = round(f * V_box / V_cyl)（记录实际 N）。
2. 随机生成 N 个圆柱（中心在盒内均匀，方向均匀球面，长度为 h，半径 r）。
3. 对当前配置做问题1 的确定性判断（split + build_connectivity）得到是否导通（0/1）。
4. 重复 M 次独立试验，统计成功次数 k -> p_hat = k/M，置信区间用 Wilson interval 或二项检验（当 M 较小或 p 附近 0/1 较极端时推荐 Wilson）。
5. 并行化：Trials 之间独立，使用 multiprocessing 或 joblib 做并行（每个进程用不同 seed）。小心避免在进程间传输大数组（把每个 trial 的工作放在进程内部完成）。
6. 在 f 网格上先粗扫（较大步长），在 p(f) 变化陡峭区域采用局部细化或二分寻找渗流阈值（参见问题3）。

问题3：如何在体积分数维度上做优化/搜索（定位临界 f）
- 粗细两级策略：
  1. 粗扫：用较小 M（例如 200–500）在粗网格上获取 p_hat(f) 曲线，找到 p_hat 从近 0 到近 1 的过渡区 [f_lo, f_hi]。
  2. 在过渡区做细化：对该区间做更密的网格或对单点用更大的 M（例如 2000–5000）获得精确 p_hat 与置信区间。
  3. 若需要高精度临界体积分数（例如估计 p(f)=0.5 的 f_c），用二分搜索策略：对当前 f 当 p_hat < 0.5 则把下界设为 f；反之设上界；在每次二分测试上使用足够大的 M 保证判定的可靠性；可采用自适应样本分配策略（在靠近 0.5 时增加 M）。
- 其他加速技巧：
  - 使用 importance sampling 或多重重用随机种子？注意：改变 N 会改变配置统计分布，无法简单重用样本；但可以固定随机种子并按顺序添加圆柱以近似“增量”方法（注意这会改变分布，需谨慎）。
  - 代理模型（surrogate）：在粗扫后用 logistic 回归或 Gaussian Process 对 p(f) 进行拟合，用拟合器估计临界值并在模型不确定区域继续取样（主动学习）。
  - 并行/分布式：把不同 f 或同一 f 的 trials 分配到不同节点。

第四部分：核心难点处理 —— 边界截断规则的算法实现细节
题里提到边界截断是关键。下面逐步给出 Python 实现思路（伪代码 + 数值细节），并说明如何处理截断后的分段、连通性、以及容易踩的坑。

一、截断思想（两种常见策略）
- 策略 A（题目前面 notebook 示例采用）：在有限盒子内把整个圆柱和盒子做几何相交，保留盒子内的圆柱片段（端点被截断）。把每一段作为独立的“片段”（segment）用于连通判定，并保持原始圆柱 id（以便调试/可视化）。
- 策略 B（周期边界 PBC）：将盒子看作拓扑环面（torus），把穿出盒子的部分 wrap-around 到另一侧；此法常用于模拟无限体或消除边界效应，但它改变了“电极”和“截断端面”概念（例如左右电极在 PBC 下需特殊处理）。题目如果明确给出了截断规则，应优先采用题目要求的截断而非 PBC。

二、如何用 Python 实现对圆柱体的截断（具体步骤）
1. 先把圆柱表示为轴线线段 from p0 to p1，半径 r。
2. 盒子范围为 [-L/2, L/2]³。
3. 求轴线线段与盒子的交集（线段与轴对盒子面的线性裁剪）：
   - 利用 3D Liang–Barsky 或 Cyrus–Beck（线段与平面裁剪）算法：对每个坐标轴 x,y,z 计算进入/离开参数 t 范围，最终得到线段在 [t_min, t_max] 的可视片段（参数 t∈[0,1]）。
   - 具体实现：对每条轴的两面（x=-L/2, x=+L/2），解 p(t) = p0 + t*(p1-p0) 与平面交点，并维护允许 t 的区间（与计算射线/线段裁剪一致）。
4. 如果 t_min > t_max：意味着轴线在盒子外且不相交 → 丢弃（该圆柱完全不在盒内）。
5. 否则，截得子线段 [p(t_min), p(t_max)]，即轴线片段；该片段构成一个新的圆柱片段（长度 = |t_max - t_min| * |p1-p0|），其半径仍为 r。将其作为 segment 加入片段集合，记录原 cylinder id 与局部索引。
6. 额外：如果圆柱端面（圆盘）与盒子平面重合需要视为“接触电极”——判断方法：若片段端点的 x 坐标 ± r 与盒子面差绝对值 <= eps（或端点本身已超出并被裁剪到面上），则该片段标记为接触该面。

三、截断后分段如何处理（节点分裂、距离计算、连通性）
- 节点分裂：你可以把每个截断片段作为独立节点加入并查集；原始圆柱如果被截断成多个片段，这些片段之间理论上仍是连通的（属于同一原体），所以应在初始化并查集时把同一原 cylinder 的不同片段先 union 在一起，还是保留其为独立节点取决于题意：
  - 如果题目把“同一圆柱的两个截断片段在盒内侧看作连通”（即材质本身连通），就应先 union 这些分段（它们之间的 surface-to-surface 距离为 0，因为原体内部是连通的）。
  - 如果题目定义为“截断后的片段彼此独立，只考虑截断后的片段之间的距离”，那就不要自动 union。 请检查题目文本（通常物理上同一物体的不同片段在内部是连通的，故应 union）。
- 距离计算：对任意两片段，精确计算“轴线到轴线最短欧氏距离 d_axis”，然后 surface_distance = d_axis - (r_i + r_j). 若 surface_distance <= thresh ➜ union。
- 连通性判断要把“接触电极”的片段当作特殊标记（或把其并查集根设为接触左/右），最后判断根集合交集是否非空。

四、具体的截断 Python 伪代码（核心函数）
- 函数：clip_segment_to_box(p0,p1,L)
  - dir = p1 - p0
  - t_min = 0; t_max = 1
  - for axis in [x,y,z]:
      for side in [-L/2, +L/2]:
         if dir_axis == 0:
            if p0_axis < -L/2 or p0_axis > L/2: no intersection
         else:
            t = (side - p0_axis) / dir_axis
            check sign to update t_min/t_max similar Liang–Barsky
  - if t_min > t_max: return None
  - return p0 + dir * t_min, p0 + dir * t_max
- 在 split_cylinder_by_box：对原圆柱应用 clip_segment_to_box；如果得到多个连续段（对于普通轴线不会得到多个不连续段，只有一段或零段），则生成 segment 对象；如果题目允许圆柱沿轴线弯曲（通常不），则更复杂。

五、容易踩的坑与注意事项
1. 轴线到轴线最短距离的数值稳定性：平行或近平行线段会导致某些公式产生数值不稳定。使用健壮的实现（参考公开的 segment-segment distance 算法）并在 denom 小于 eps 时做特殊处理（投影到端点距离）。
2. 截断逻辑与“接触电极”判定：截断后端点可能刚好与面相切或数值上略超出边界，建议用一个小 eps（如 1e-9 * L）做容差判断。
3. 是否自动把同一原始圆柱的所有片段 union：通常应 union（物理上同体连通），否则会低估连通性。
4. 候选对筛选策略：千万不要直接 O(M^2) 比较所有片段（M 很容易上万）。用 KD-tree 或分箱粗筛以降低到 O(M log M) 或 O(M) 复杂度。
5. 并行时的随机种子与复现：每个 trial 使用独立的 seed（例如 seed_base + trial_id + hash(f)），并把 seed 写入日志，便于复现失败样例。
6. 周期边界与截断的选择：PBC 会改变“电极接触”的定义（会出现穿透），所以只有在你想模拟无限大材料时采用；题目若要求“盒子内截断”，则严格按照截断实现。
7. 单精度/双精度与尺度：单位 nm 导致距离值较大，使用 double（float64）通常足够，但若你把数据归一化到 0-1 范围可减少数值问题并加速 KD-tree。

性能估计：
- 假设 N 原始圆柱 -> M 片段（通常 M ≈ N，但截断不会增加数量太多），KD-tree 构建 O(M log M)，每个点平均查询邻居数 k，精确距离计算为 O(k)；总体接近 O(M log M + M*k)。
- 若 N~1e4 且每个段与邻居数 k ~ dozens，则单次 trial 可能耗数秒到数十秒，M=500 trials 就需要大量时间，因此并行化与 C/numba 加速是必要的。
